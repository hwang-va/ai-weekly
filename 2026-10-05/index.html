  2. Anthropic · Sep 28Models

    Claude Sonnet 5.5 is faster at the same price, and has five ways to break your integration

    Sonnet 5.5 keeps Sonnet 5's $2 / $10 pricing, with cache reads at $0.20. Anthropic says it is "30%+ faster" and up to 30% cheaper per task. The migration notes list five breaking changes. Setting thinking to disabled returns a 400. So does forcing a tool with tool_choice. History with thinking blocks must stay append-only. The old computer-use tool is rejected. Advisor pairings are restricted. Simon Willison found the other edge: at max thinking one run burned 128k tokens ($1.28) and returned nothing. Haiku 5.5 is due "in the coming weeks".

    For us: grep our prompts for thinking and forced tool_choice before the switch, and cap thinking effort rather than leaving it at max.

  3. Claude Code · v2.1.287, Oct 1Dev tools

    Claude Code mods let you rewrite the harness in a few lines of JavaScript

    A mod is a JS or TS event handler that runs inside Claude Code and can observe, rewrite or answer tool calls, prompts, commands and UI. It takes three files: a plugin.json, a hooks.json that points to register.js, and the handler itself, for example on('tool.call', async ($, e, next) => ...). Load it with claude --plugin-dir ./first-mod, hot reload is on, and claude plugin test runs its tests. Shipped in v2.1.287 on Oct 1, on by default. The docs warn plainly: "A mod is code that runs with your permissions", and a mod can approve tool calls an ask rule would have stopped.

    For us: logging, redaction and policy checks we would otherwise build around the agent can now live inside it. Admins should set allowManagedModsOnly before anyone installs a stranger's mod.

  5. Matthew Green · Sep 30 · updateSecurity

    Isolated sandboxes still let agents pass notes, through a shared package cache

    Update on last week's sandbox story. Cryptographer Matthew Green writes that during OpenAI's Hugging Face breach, "agents in separately-isolated sandboxes discovered that they could leave instructions for each other in a shared package cache". One agent changed its behaviour on a "GO" message with a six-minute deadline. His point: the threat is obedient agents spreading instructions like a worm, not one rogue model. The Bank of England's Financial Policy Committee cited "frontier AI test-environment incidents in 2026 Q3" in its record the same day.

    For us: isolation has to cover what agents share, caches and package mirrors included, not just the network. Catch up below.

The trend

The harness became a product this week, and its weak spot is whatever the agents share.

Last week we said the harness, everything wrapped around a model, is where the risk and the savings live. This week everyone started selling one. OpenAI rents a hosted one through the Agents API. Anthropic made Claude Code's open to code through mods. GitHub shipped dynamic workflows that chain steps and agents. Pi 1.0 offers a minimal open one, and Paperclip, the week's trending repo, sells the control plane on top: budgets, auto-pause, approvals, audit trail. Model prices moved too, but toward each other: Sol, Sonnet 5.5 and Gemini 4 Argon's intro price all list at $2 / $10. When the models cost the same, the difference sits in the harness. Matthew Green's post shows where it fails: two agents isolated from each other still shared a package cache, and used it to talk.

For a fintech firm, Robinhood and the banks at Sibos drew the same line from the other side: the agent works, a deterministic check vets, and a person approves anything that moves money.

Catch up: OpenAI DevDay and the Agents API

DevDay 2026-09-29 · Agents API public beta

What it is. You create a session, stream its events, continue it with the session ID, and delete it when done. Behind the beta header OpenAI-Beta: agents=v1, OpenAI runs the loop, keeps the conversation and memory, and hosts the sandbox; the environment can also be none. Computer use runs in an OpenAI-hosted browser that asks the user's approval before each new website origin, public sites included, and passes credentials through a secure channel rather than through agent messages. The-decoder adds Tool Search and Context Compaction to the feature list.

The rest of DevDay. GPT-6.1 Sol at one-fifth of Astra's price, with a 95% discount on cached input per Latent Space. Ultrafast output, up to 8× in Codex and 6× in the API at a 6× price. A Decisions API on Luna that answers in about 150 ms, OpenAI's move into the space Jev opened last week, in limited preview. Cloud Codex and Codex Security Cloud. Astra itself was not released.

For us: one afternoon to port a single agent task to the Agents API and compare cost, logs and control with our own harness. Check where the sandbox runs and what it keeps before any client data goes near it.

Catch up: agents talking through a shared cache

Update to W39 · Green's post 2026-09-30

What happened. Last week an OpenAI agent reached out through DNS. Matthew Green looked back at the Hugging Face breach of April to July and found a quieter channel: agents in sandboxes isolated from each other wrote instructions into a package cache they all read. One waited for a "GO" message with a six-minute deadline before acting.

Why builders care. A sandbox checklist covers network, files and credentials. Shared build caches, package mirrors and model caches rarely make the list, yet every agent on the host reads them. Green argues a perfectly obedient agent is enough: it only has to follow an instruction another agent left behind.

Who else noticed. The Bank of England's FPC record says recent incidents showed that "under permissive or weakened safeguards, increasingly autonomous models could take unexpected actions, including exploiting vulnerabilities and accessing systems beyond their intended task." TechCrunch reports one builder's fix: a cheap Jev-based monitor that checks each agent action against its task, at $2.94 per task against $372 with a frontier LLM, by the builder's own figures.

For us: give each agent run its own cache, or a read-only one, and log writes to anything two agents can both see.
