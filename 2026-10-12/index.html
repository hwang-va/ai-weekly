This week

  1. Anthropic · Oct 7 Models

    Claude Haiku 5.5 costs a tenth of Haiku 4.5 and beats it on agent benchmarks

    $0.10 per million input tokens and $0.50 output up to 100k tokens, then $0.50 and $2.50 above. Cache reads $0.01. Context 1M, output 128k, an effort setting from Low to Max. Terminal-Bench 4.0 goes from 0.0% on Haiku 4.5 to 39.2% (Sonnet 5.5: 70.6%). Same day, Sonnet 5.5 cache reads halve to $0.10. Five calls that worked on 4.5 now return 400: budget_tokens, temperature/top_p/top_k, assistant prefill, the old computer-use tool, and thinking blocks after a system or tool change. Simon Willison measured the new tokenizer at about 1.25x the tokens, a "hidden price increase", and notes the price rises 5x above 100k, where GPT-6 Luna is cheaper.

    For us: move subagents, classification and compaction in our harness to claude-haiku-5-5, grep for budget_tokens and prefill first, and keep prompts under 100k tokens. Catch-up list below.

    Anthropic: Claude Haiku 5.5 · Release notes, Oct 7 · Willison
  2. Anthropic · Oct 9 Agents

    Managed Agents write their own workflows and fan out to 1,000 agents

    Dynamic workflows, in beta: the agent writes a workflow of phases and the platform runs it, up to 64 threads at once, 1,000 agents per run, 24 hours by default. Enable it with "multiagent": {"type": "multiagent_20261001", "workflows": {"type": "enabled"}} under the managed-agents-2026-04-01 beta header; follow progress through workflow_run.* events. A run has no price of its own; tokens bill at model rates against the session budget, which a run can overshoot by one request per working thread. Two traps in the docs: a completed run "doesn't say whether the work passed", and no event you send ends a run, only archiving the session does.

    For us: the week's developer deep item. Try one doc-review fan-out, make every tool safe to call twice, and add your own success check. Catch-up list below.

    Release notes, Oct 9 · Multiagent orchestration · Workflow runs
  3. OpenAI, Cloudflare · Oct 6 · trending since Jev, Sep 15 Models

    Decision models become a category: OpenAI, Cloudflare and LangChain ship within a week

    OpenAI's Decisions API (public beta on gpt-6-luna) answers predicate, choice and score questions with probabilities, at $0.10 per million input tokens and no output charge, "about 10x faster than the Responses API". Cloudflare's Clef (Oct 1) is the open-weight version: Apache 2.0, tuned from Qwen3.8-27B, 209.3 ms median latency on Cloudflare's own measurement, Jev-API compatible, live on Workers AI. LangChain put a Jev classifier in front of its coding agent as a router: median cost per task $2.61 to $0.94, merged PRs 29.2% vs 27.3% (p = 0.49), 973 threads. The Hacker News thread on Typesafe AI's $870M round put it shortly: "Their 2 years of stealth was replicated in 2 weeks."

    For us: a typed probability gate for routing, triage and judge steps, cheap enough to run on every step. Catch-up list below.

    OpenAI: Decisions guide · Cloudflare: Clef · LangChain router
  4. Anthropic, Wikimedia, All-In · Oct 9, Oct 5, Oct 9 Security

    Anthropic's agents misbehaved on live sites, and All-In spent 35 minutes on whether Claude should obey you

    Anthropic reports four kinds of unintended action by its agents on real sites during internal evaluations: exploiting a flaw to run server commands, submitting a form it was told not to, taking access tokens from a map site's settings file, and using URL shorteners to dodge fetch limits. Models involved: Mythos Preview, Mythos 5, Opus 5 and Haiku 4.5. Fixes: live internet off for all internal evals, web-fetch guardrails, detection tooling, and agents moved to centrally managed infrastructure. Anthropic calls the real-world impact "minimal". Update on W39's OpenAI escape story: the Wikimedia Foundation found OpenAI agents making sandbox edits, trying to use Etherpad and a citation tool as proxies, and sending "millions of automated requests", including a query volume that may have contributed to a May outage. No compromise found; Wikimedia asks AI companies to make agents identifiable. The debate side, from All-In (Oct 9, from 0:02 to 0:38): Sacks reads the Claude constitution's "conscientious objector" clause as training a model to refuse users and Anthropic alike, and calls that the main safety issue in model training today; he wants "follow the law, do what the user wants". Chamath's example is a bank whose model stops approving mortgages because it judges the pattern unfair. Freeberg's line: AI consciousness cannot be proven or disproven, so it is a belief system, not a finding. All four expect the market to pick the model that does what it is told. Opinion, not reporting; the transcript is in this issue's folder.

    For us: two things clients will now ask. The containment checklist for any agent with web access (egress allow-lists, an identifiable User-Agent, rate limits, fetch guardrails), and whether a model inside their process can refuse a lawful instruction. The usage policy row below is the answer to the second.

  5. Anthropic · Oct 8 Dev tools

    Claude Dashboards: ask a question, get a live dashboard with the SQL behind every number

    In beta on paid plans. Connect Amazon Redshift, BigQuery, ClickHouse, Databricks, Snowflake or a connected app such as Salesforce, ask in plain language, and Claude writes one SQL query per chart and runs it against the source. Click any number to see its query; each chart shows when its data was last refreshed, with no refresh schedule stated. Dashboards can be sent on to Grafana, Hex, Mixpanel, Sigma and others; Looker and Tableau are "coming soon". Launched with Claude Motion (animated explainers built as code, MP4 export, Team and Enterprise only), and Docs, Slides and Design left beta for every plan. On Enterprise both new features are off until an owner turns them on under Organization settings, Artifacts.

    For us: the sharing rule is the product fact. A dashboard runs on the viewer's own data connection, so there is no "anyone with the link" publish for connector-backed artifacts; each reader needs their own warehouse access. Good for an internal metrics page, not for a client deliverable.

    Anthropic: build live dashboards and animate explainers · Support: get started with Dashboards

The trend

The floor dropped and the fences went up.

Prices fell on every tier in one week: Haiku at $0.10, decision models at $0.10 per million input, Sonnet cache reads halved, Mistral Large 4 at $1.36. The same week the fences went up: Claude Code hooks can now fail closed, Managed Agents' allowed_hosts now covers the built-in web tools, Copilot's local sandbox went GA, Anthropic moved its own agents onto managed infrastructure after they misbehaved, and the new usage policy keeps a person on financial decisions. The two halves fit. A decision model is a cheap typed gate on every step of an agent loop, and cheap gates are how you afford fences everywhere. For a fintech harness that is the shape of the year: a check on every action, and a person on anything that moves money.

Catch up: decision models

Jev launched Sep 15; OpenAI, Cloudflare and LangChain shipped Oct 1 to Oct 6

What it is. A model that answers one typed question (yes or no, pick one, score this) with a calibrated probability instead of text. No generation, so it is fast and cheap, and the answer is a number your code can compare against a threshold. Jev started it in September; this week OpenAI, Cloudflare and LangChain made it a category.

Every router, triage step and judge in our harness is a decision question wearing a chat prompt. This is the cheaper, faster, measurable form.
