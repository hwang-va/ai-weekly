This week

  1. LiteLLM, Datadog, Hacker News · Oct 21 Security

    A poisoned LiteLLM release stole keys from the proxy many agent stacks route through

    LiteLLM 1.107.0 on PyPI and Docker was malware for about two hours on Oct 21. The attacker used three developers' GitHub CLI tokens, disabled branch protection and built from a lookalike fork, Berri-AI/litellm. The stealer ran at every Python start and took cloud keys, SSH keys and every provider key in the proxy database. LiteLLM says the tokens may have leaked through its own logs of Claude Code responses.

    For us: pin litellm==1.106.2 or earlier wherever an LLM proxy sits in our stack, treat agent logs as places credentials leak, and keep keys out of the agent's reach. Catch-up list below.

    LiteLLM: security incident · Datadog Security Labs · Hacker News (595 points)
  2. Axios via CBS, Anthropic · Oct 21 to 23 Fintech

    Banks found customers' AI agents inside their accounts, the same week Anthropic launched one that asks first

  3. Anthropic · Oct 19 to 23 Dev tools

    Claude API version 2026-10-21 rejects temperature, and Claude Code now logs every blocked tool call

    On API version 2026-10-21, sending temperature, top_p or top_k returns 400, even at the default. New SDK majors (Python 2.0, TypeScript 1.0, Go 2.0, Java 3.0) send the new version by default; 2023-06-01 callers are unaffected. Claude Code 2.1.307 adds the claude_code.safety_event OpenTelemetry event for each tool call a rule, hook or sandbox stopped. 2.1.309 makes claude ultrareview require --trust-workspace in scripts.

    For us: pin SDK versions, then run /claude-api api-version on a branch before any bump. safety_event is the approval audit trail our harness traces were missing. Fix CI that calls ultrareview.

The trend

Agents hit the perimeter from both sides, and the controls started shipping as products.

Last week the finance keynotes described "deterministic controls outside the model". This week they got names. Customers' agents reached the bank with the customer's password, and the banks said no; Anthropic shipped an agent that asks first and will not trade. A poisoned proxy release showed that an agent's logs and environment are where keys leak; NVIDIA's OpenShell is a runtime that never shows the agent a real credential. The Claude platform added per-customer user profiles, and Claude Code emits a safety_event for every blocked tool call. For a fintech harness the checklist is concrete: credentials the agent cannot read, an identity per end customer, approval before money moves, a trace of every refusal.

Catch up: the LiteLLM supply-chain attack

Incident Oct 21, 2026 · LiteLLM post updated since

What it is. LiteLLM is the open-source proxy many teams put between their agents and model vendors. One release of it was malware, published through the project's own pipeline with stolen developer tokens. PyPI pulled it in 1 h 43 min; Docker tags pointed at it for 2 h 33 min.

If any machine or image installed 1.107.0 with outbound internet, assume exfiltration: rotate the instance role, every provider key in the proxy database, master and virtual keys, and DATABASE_URL.

  • N Trending · NVIDIA OpenShell: an agent runtime that never shows the agent a key

    For us: the LiteLLM lesson as a runtime. Compare its policy model with our sandbox before we build more of our own.
