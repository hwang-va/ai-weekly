  2. Cursor, Phorion, Hacker News, LiteLLM · Oct 29 to 31 Security

    A tampered Claude Code extension on Cursor's marketplace planted an SSH backdoor for eleven hours

    Versions 2.1.312 and 2.1.313 of the Claude Code extension on the Cursor Marketplace carried code that ran before activation: it added an attacker's key to ~/.ssh/authorized_keys, opened a reverse SSH tunnel, installed persistence, and beaconed the names of environment variables matching KEY, TOKEN or SECRET. Cursor says it was live from 2:27 am to 1:35 pm PT on Oct 29 and was "not developed by Anthropic"; the official distribution is unaffected. LiteLLM now says its own attacker took GitHub tokens from proxy logs of Claude Code responses.

    For us: if anyone installed Claude Code through Cursor on Oct 29, run Cursor's remediation script and rotate every key that user could reach. Pin extension sources; stop logging agent response bodies. Catch-up list below.

    Cursor: security notice · Phorion advisory · Hacker News (985 points) · LiteLLM post, updated Oct 30
  3. Anthropic, GitHub · Oct 27 to 31 Dev tools

    Claude Code got a hard write boundary and dropped the safety event we flagged last week; GitHub's Agentic Workflows went GA, read-only by default

    Claude Code 2.1.314 adds permissions.blockWritesOutsideWorkingDirectories: Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode. 2.1.312 stopped sending the claude_code.safety_event we reported last week and caps hooks at 24 per session; Opus 4.8 fast mode ends Nov 30. GitHub Agentic Workflows are GA: Markdown that compiles to Actions, read-only by default, a sandbox behind a firewall, a threat-detection job on every proposed change. Octoverse: agents now start over 40% of pull requests.

    For us: the developer deep item: set the write boundary in managed settings today, and rebuild anything that read safety_event. Agentic Workflows is the reference design for an agent in CI; catch-up list below.

The trend

The agent's supply chain became the attack surface, and the gatekeepers started publishing their rules.

Two weeks ago a poisoned proxy release; this week a tampered IDE extension, and a stealer that asks Claude which victim is worth most. The replies came as controls, not advice: a hard write boundary in Claude Code, read-only defaults and a firewall in GitHub's agent workflows, lockfiles for Actions, a scanner for skills, a permissions classifier in Copilot. On the money side the gatekeepers said the rule out loud: Schwab lets agents in through its MCP server or not at all, the SEC will test whether AI governance works in practice, and a tax benchmark shows why: the best agent passes one task in ten, mostly by acting on assumptions nobody checked. For our harness the checklist grows: pin what the agent installs, bound where it writes, and reach client data only through a server the custodian controls.
