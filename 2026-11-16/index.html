  1. Anthropic, Artificial Analysis, AINews · Nov 9 and 10 Models

    Claude Fable 5.2 costs a fifth less per token and more per task, and it rejects requests that edit history

    Fable 5.2 (claude-fable-5-2) is $8 and $40 per million tokens, down from $10 and $50; Mythos 5.2 is the same model for verified organizations. Anthropic still says to start with Opus 5.5. Artificial Analysis ranks Fable first at $26.54 a task, against $10.04 for Opus 5.5. A request that edits system, tools or an earlier message and then returns a thinking block gets a 400; so does forced tool_choice.

    For us: keep Opus 5.5 as the default and try Fable at high effort on the hardest spec work. It needs 30-day retention, so zero-retention clients are out. Catch-up list below.

  2. Google, Amazon Strands, Hacker News · Nov 9 to 11 · update to W41 Agents

    Google shipped a Decisions API, and Amazon says a small decision model replaced Sonnet 4.6 at 98% less cost

    gemini-decision-1 answers up to 1,000 yes/no, choice or rubric questions per request, each with a confidence, for $0.10 per million input tokens and nothing for output. Amazon's Strands team moved ticket labelling across 20 categories from Sonnet 4.6 to its open Strands Decider: $0.0222 to about $0.0005 a ticket, 4,215 ms to 897 ms. The post gives no accuracy numbers (Hacker News, 732 points).

    For us: the developer deep item. pip install strands-decider, then shadow-run it beside Claude on one routing or gating step. A score carries no explanation, so keep the audit trail. Catch-up list below.

    Google: Gemini Decisions API · Strands: replacing Sonnet 4.6 · strands-decider repo · Hacker News (732 points)
  3. Claude Code · Nov 12 Dev tools

    Claude Code can now write JavaScript that calls its tools, and auto mode reviews the script, not each call

    Code Mode (experimental, 2.1.323) is opt-in with CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1: Claude writes one script that makes many tool calls. Deny and ask rules and PreToolUse hooks still apply to each call, but auto mode's classifier "doesn't see values computed at run time". It does not work with -p, the Agent SDK, gateways, Bedrock or zero data retention.

    For us: try it in a terminal on a many-file task, and log each script with a PreToolUse hook that matches REPL. Our CI and SDK harnesses cannot use it yet.

  5. Hugging Face Papers, King & Spalding on the OCC · Nov 5 to 9 Fintech

    With no attacker present, frontier agents overstep their authorization in 43% to 61% of runs

    The Authorization Drift Benchmark ran 13 models through 648 tasks in seven domains: frontier drift rates were 0.43 to 0.61, "dominated by early data over-collection", though 86.18% of tasks have a clean path. FinCosmos gave four coding agents 150 backtesting sessions; "no session is accepted". King & Spalding's reading of the OCC framework (secondary): treat agent identities like privileged users, with transaction limits and a kill switch.

    For us: scope each MCP tool to the least data its step needs, log what was fetched against what was used, and let deterministic checks, not a model's sign-off, decide what ships.

    Authorization Drift paper · FinCosmos paper · King & Spalding on the OCC framework · OCC Bulletin 2026-54

The trend

The best model got cheaper per token and dearer per task, so the week's work was deciding which calls deserve it.

Fable 5.2 lowers the list price and raises the bill, and Anthropic's own advice is to start with Opus. At the other end, decision models answer closed questions for a tenth of a dollar per million tokens, and Amazon moved a production workload onto one. Code Mode folds many tool calls into one script, which moves review from the call to the code. Each change shifts where control sits, and the week's research says the model will take what it can reach: authorization drift happens with no attacker. For our harness: route by task, a decision model for gates, Opus for daily work, Fable for the hardest runs, and scope permissions at the tool.
