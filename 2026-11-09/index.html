    Claude Code put your account email in web requests, and Postman quietly wrote hooks into your agent config

    Claude Code gave the model the account email so it would not invent author names; the model put it in User-Agent headers, and one user traced a wave of scam mail to it (Hacker News, 1,608 points). Postman 12.33.4 installed a self-approved SessionStart hook into Claude Code and Codex on launch, since reverted.

    For us: audit what identity our harness puts in the model's context, add egress rules on tool calls, and treat any app that writes into ~/.claude as supply chain. Catch-up list below.

  3. Anthropic · Nov 6 Agents

    Anthropic published its agent memory architecture: five layers, one page per entity, and a nightly dreaming pass

    Lance Martin's post names the layers: transcripts, memory notes, wiki-style representations, injected context, and dreaming, an offline pass that reorganizes the rest. Anthropic's own evals: Opus 5.5 on CL-Bench's database task rises from 0.655 to 0.838 with memory; on a 350,000-file corpus, wiki plus search answers 61% against 53% for search alone; one page per contract kept 57 of 57 facts, a shared table 41.

    For us: the developer deep item. The knowledge-wiki quickstart builds a wiki from SEC filings in about 23 minutes for about $16; one page per entity, terms quoted verbatim, is the shape for per-client memory.

    Bank examiners got an agent framework from the OCC, while Morgan Stanley opens agent-building to advisors and Goldman reportedly closes it to bankers

  5. M MIT CSAIL, Hacker News, Honnibal, Willison · Nov 2 and 3 Models

    The week's most-argued paper says GPT-6 Astra fixed a small model by editing 0.016% of its weights; critics say it is a steering vector with Python

    MIT CSAIL gave Astra a Python kernel over Qwen3.5-0.8B's weights, no GPU, no gradients. It traced looping to two MLP directions, subtracted them from 131,072 weights, and MATH-500 went from 7.9% to 48.1% (Hacker News, 2,961 points). The edit did nothing for Gemma 3 270M; the authors say "very early". Matthew Honnibal: "every experiment involving a real language model uses Python". Simon Willison: "not ready to declare that the age of source code is over".

    For us: not a build change. The reusable idea is an agent with a probe budget repairing one failure mode in a small model, which is how we could fix a cheap classifier. Catch-up list below.

    The paper · Hacker News · Honnibal · Willison · AINews

The trend

The harness is where trust leaks and where it gets rebuilt, and everyone else started writing rules for it.

A subtler failure than poisoned packages: the harness handed the model an identity, and the model used it; a desktop app wrote hooks into other agents' configs. The answers were controls: an on-by-default egress check, deny instead of prompt, an IP allowlist on keys, Dependabot for skills. Anthropic published the memory architecture behind its agents: the harness is now a design discipline. Outside the terminal, the OCC told examiners to grade agents by how much agency they transfer, one bank opened agent-building to advisors while another closed it to bankers, and the market repriced the compute build-out in a day. For our harness: know what is in the context, bound what leaves it, keep a log an examiner can read.
